# CN-Visual-Novel

A Chinese-language visual novel built with Ren'Py, with art generated via ComfyUI (SDXL). Grade 1 content lives under `Grade1/`.

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/` — there is no git remote, so `gh`/`glab` do not apply. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` at the root plus `docs/adr/`. Existing narrative and art design docs live in `Grade1/Design/`. See `docs/agents/domain.md`.
